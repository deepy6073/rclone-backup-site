rclone backup client

A personal-use desktop tool that keeps an encrypted backup of one workstation in Google Drive.

What it is

This OAuth client belongs to rclone, an open-source command-line program for managing files in cloud storage. It is registered for a single private use: copying an encrypted archive of the owner's own working directory to the owner's own Google Drive account.

How it works

  • The archive is created locally and encrypted with AES-256 before it is uploaded.
  • Uploads go to one dedicated folder, backup/workspace, in the user's own Drive.
  • Old archives are rotated automatically; the newest seven are kept.
  • The tool runs on the user's machine only. There is no server, no cloud component and no third party.

Who uses it

One person — the account owner. The application is not distributed, published or offered to other users.
